# Bunny Rush — MERN Stack Game

## How to Run

### Prerequisites
- Node.js v18 or above
- MongoDB running locally

### Backend
cd Backend
npm install
npm run dev
Server runs on http://localhost:5000

### Frontend
cd Frontend
npm install
npm run dev
Game runs on http://localhost:5173

### External API
HeartGame25 API: https://marcconrad.com/uob/heart/api.php?out=json
